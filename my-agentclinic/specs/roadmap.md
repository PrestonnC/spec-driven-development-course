# Roadmap

High-level implementation order in very small phases. Each phase is a shippable vertical slice.

## Phase 1: Hello Hono ✅ Complete
- Add Hono and the Node server; serve a home page at `/`
- Dev script with reload

## Phase 2: Layout
- Shared page layout component (header, nav, footer)
- Base styles, attractive and responsive in a modern browser

## Phase 3: Agents
- Agent list page with seed data
- Agent detail page

## Phase 4: Ailments
- Ailment list page with seed data
- Link ailments to the agents who suffer from them

## Phase 5: Therapies
- Therapy list page with seed data
- Link therapies to the ailments they treat

## Phase 6: Appointments
- Booking form: pick an agent and a therapy
- Appointment list page

## Phase 7: Dashboard
- Dashboard home summarizing agents, ailments, therapies, and upcoming appointments
- Make the dashboard the main entry point

## Phase 8: Polish
- Tests for key routes
- Visual and copy polish for the playful tone
